# korotkiy_url - Метрики (ДЗ 2)

## Стек

- Go (net/http), prometheus/client_golang
- PostgreSQL 17, postgres-exporter
- VictoriaMetrics Single, через helm-чарт. Сбор метрик делает сам сервер (`server.scrape.enabled: true`), агент не используется.

## Экспортеры
- Метрики рантайма Go (`go_*`, `process_*`): `promhttp.Handler()` из `prometheus/client_golang`, отдаются на отдельном порту 9090
- Метрики Postgres: `postgres-exporter`, второй контейнер в поде `db`, порт 9187

## Бизнес-метрики

| Метрика | Тип | Описание |
|---|---|---|
| `korotkiy_url_links_created_total` | Counter | сколько ссылок создано |
| `korotkiy_url_redirects_total{result}` | Counter | сколько редиректов, `result` = `found` / `not_found` / `error` |
| `korotkiy_url_redirect_duration_seconds` | Histogram | время обработки редиректа |
| `korotkiy_url_links_total` | Gauge | текущее число ссылок в БД, считается запросом `COUNT(*)` при каждом скрейпе, поэтому не сбрасывается при рестарте пода |
