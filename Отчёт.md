# korotkiy_url - SLA (ДЗ 5)

## Пробер

blackbox_exporter раз в 15с запрашивает `http://backend.default.svc:8080/s/kuber` (существующая для редиректа ссылка) и проверяет, что сервис отвечает 302 (редирект успешен).
Подключён как job `backend-redirect` через `server.scrape.extraScrapeConfigs` в values чарта `victoria-metrics-single`.

# Метрики

`korotkiy_url_redirects_total{result}` - тип Counter, число редиректов. `result` может быть один из `found` / `not_found` / `error`
`korotkiy_url_redirect_duration_seconds` - тип Histogram, время обработки редиректа (бакеты от 5мс до 10с)
`probe_success{job="backend-redirect"}` - тип Gauge, результат пробера: 1 если проба успешна, иначе 0

## SLI

```
# SLI 1: доступность (RBSLO); SLO=99%; SLA=98%
sum(rate(korotkiy_url_redirects_total{result!="error"}[2m]))
/
sum(rate(korotkiy_url_redirects_total[2m]))

# SLI 2: latency < 100ms (RBSLO); SLO=95%; SLA=90%
sum(rate(korotkiy_url_redirect_duration_seconds_bucket{le="0.1"}[2m]))
/
sum(rate(korotkiy_url_redirect_duration_seconds_count[2m]))

# SLI 3: пробер (TBSLO); SLO=99%; SLA=98%
avg_over_time(probe_success{job="backend-redirect"}[2m])
```

## Изменения приложения для скринкаста

Добавлена ручка `POST /admin/chaos?fail=x&slow=y` на порту метрик 9090. Создает искусственное замедление/ошибки на редиректах

Ещё используется простой шелл скрипт для генерации нагрузки:

```bash
while true; do
  curl -s -o /dev/null localhost:8080/s/kuber # существующая ссылка
  curl -s -o /dev/null localhost:8080/s/does-not-exist # несуществующая ссылка
  sleep 0.2
done
```
